# Calculator

Консольный калькулятор (`calc.exe`) с плагинами. Поддерживает `+ - * / ()`.
Функции и операторы подгружаются во время работы из DLL в папке `plugins`
рядом с exe: `sin(x)` (в градусах), `ln(x)`, оператор `^` (степень).

## Сборка

cmake -S . -B build -A x64
cmake --build build --config Debug

Результат: `build\Debug\calc.exe` и `build\Debug\plugins\.dll`.

## Запуск

build\Debug\calc.exe
> 16 + 4 * (3 - 1)
24
> 2^4 + sin(90)
17

## Плагины

Плагин - DLL, которая экспортирует `get_plugin_function()` и возвращает структуру `PluginFunction` (см. `include/plugin_api.h`): имя, число аргументов и функцию вычисления. Имя функции берётся из структуры, а не из имени файла.

## Обработка ошибок

Некорректная DLL, DLL без экспорта `get_plugin_function`, дубли имён: предупреждение, плагин пропускается.
Нет папки `plugins` или в ней нет DLL: предупреждение, доступны `+ - * / ()`.
Ошибка в плагине (например, `ln(-100)`), деление на ноль, синтаксическая ошибка: сообщение `Error: ...`, программа продолжает работу.
